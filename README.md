# AnyCompany 报销政策库

本仓库是 AnyCompany **财务部**维护的报销政策正式发布位置。

> ⚠️ 这是一个用于教学演示的**虚构公司**的**虚构政策**。金额、流程、组织都是模拟的，禁止用于真实制度。

## 报销类别

五个：

`travel`（差旅） · `meal`（餐饮招待） · `training`（培训学习） · `equipment`（设备用品） · `other`（其他）
