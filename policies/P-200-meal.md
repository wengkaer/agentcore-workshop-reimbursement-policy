# P-200 餐饮与招待费报销标准

`meal` 类别下有四种性质完全不同的支出，标准各不相同。提单时请在 `note` 里
写明是哪一种。

## 200.1 加班餐

| 项 | 标准 |
|---|---|
| 单人单次上限 | 60 元 |
| 适用条件 | 工作日 20:00 后仍在工作，或周末到岗 |
| 需注明 | 加班日期 |

## 200.2 团队聚餐 / 团建

| 项 | 标准 |
|---|---|
| 人均上限 | 200 元 |
| 单次总额上限 | 5000 元 |
| 频次 | 每个团队每季度不超过 2 次 |
| 需注明 | 参与人数、团队名称 |

**未提供参与人数时，按单次总额判定** —— 总额在 5000 元以内即视为合规，
不因缺少人数而拒单。人均是否超标由部门负责人在审批时核。

## 200.3 客户招待

| 项 | 标准 |
|---|---|
| 人均上限 | 400 元 |
| 单次总额上限 | 8000 元 |
| 需注明 | 客户单位名称、双方参与人数 |

- 酒类**仅客户招待可报**，且金额不得超过该单总额的 30%。
- 招待对象为**公务人员**的，任何金额均不予报销 —— 无论标准内外。
- 同一客户单位每月招待不超过 3 次。

## 200.4 内部会议茶点

会议期间的茶歇、简餐，按**人均 50 元**、单次总额 2000 元以内报销，
需注明会议主题与人数。

## 200.5 与差旅补贴互斥

出差期间已领取 [P-100](P-100-travel.md) 差旅补贴的日期，不得再报 200.1 / 200.2 的
餐费。客户招待餐（200.3）不受此限。

## 200.6 不予报销

- 个人日常三餐（非加班、非出差、非招待）；
- 单独购买的烟、酒、礼品卡（并入礼品，本仓库不涉及）；
- 无实际业务对应的「凑票」餐费；
- 娱乐场所消费（KTV、酒吧、会所等）。

## 判定要点

- 可直接判定：总额是否超过对应场景的上限；
- 场景无法从 `note` 判断时，取**最宽松**的适用上限（即客户招待的 8000 元），
  按 APPROVE 处理并在理由里注明「未说明餐费性质，需补充」;
- 人均标准需要人数，属人工复核项，不作为拒单依据；
- `note` 中明确出现 200.6 所列情形（如「客户 KTV」「公务人员宴请」）时判 DENY。
